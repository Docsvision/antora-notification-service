= Описание карточек модуля

{ns} использует следующие справочники и карточки для хранения настроек и реализации логики формирования и отправки уведомлений.

[#settings-directory]
== Справочник {nss}

Справочник используется для регистрации компонентов, применяемых в карточках рассылки и настройки уведомлений. По функциональному назначению компоненты разделены на группы:

* xref:user:settings-components-context.adoc[Компоненты контекста данных уведомлений].
* xref:user:settings-components-transform.adoc[Компоненты преобразования данных].
* xref:user:settings-components-send.adoc[Компоненты отправки уведомлений].
* xref:user:settings-components-source.adoc[Компоненты источника данных].
* xref:user:settings-components-post-process.adoc[Компоненты постобработки (опционально)].

Справочник поставляется в составе модуля _{ns}_.

[#events-directory]
== Справочник событий уведомлений

Справочник отвечает за регистрацию событий, которые требуют уведомлений. Когда возникает определенное событие, например, завершается задание на согласование, требуется отправка уведомлений по нему.

События, зарегистрированные в справочнике,
используются в карточке настроек рассылки, таким образом рассылка подписывается на выбранное событие.

[#sett-card]
== Карточка настроек уведомления

Карточка настроек уведомления (шаблон уведомления) содержит информацию, по которой формируется и отсылается уведомление. Информация будет
получена на основании данных карточки.

Обычно шаблон уведомления специфичен для каждого типа\вида карточки.

[#sending-card]
== Карточка настроек рассылки уведомлений

Карточка настроек рассылки уведомления определяет, при каких условиях формируются уведомления по одному или нескольким выбранным шаблонам. Таким условием может быть или зарегистрированное событие из справочника событий, или наступление заданного времени по расписанию.

[#send-log]
== Журнал рассылки уведомлений

Модуль поставляет пользователю возможность работать с Журналом рассылки уведомлений. Для работы журнала с модулем поставляются следующие компоненты:

. `GridCardRowView` -- плагин грида {wc}а, предназначенный для открытия разметки строки Журнала расылки уведомлений.
. Поисковый запрос _Поиск журналов_ и представление для просмотра журнала рассылки уведомлений.
+
.Поисковый запрос "Поиск журналов"
image::user:search-query.png[Поисковый запрос "Поиск журналов"]
+
. Представление с названием _Поиск по журналу_ для отображения строк журнала в папке с параметрическим поиском.
+
.Настройки представления "Поиск по журналу"
image::user:log-settings.png[Представление "Поиск по журналу"]
+
.В настройках представления:
* _LogRowId_ -- идентификаторы строк секции Журнал, по умолчанию колонка скрыта. Наличие скрытого/видимого столбца с названием _LogRowId_ активирует плагин грида.
* _Статус_ -- варианты значений "Успешно" и "Ошибка".
+
. Папка _Поиск по журналу_ с поисковыми параметрами
+
.Поисковые параметры для папки "Поиск по журналу"
image::user:parameters.png[Поисковые параметры для папки "Поиск по журналу"]
