[NOTE]
====
Без дополнительной реализации {ns} может использовать только следующие события из справочника:

* Задание начато,
* Задание завершено,
* Задание на приёмке,
* Задание на доработке.

Родительское событие "Задание (общее уведомление)" работать не будет.
====
