= Локация "{ns}"

После установки модуля в главное меню {wc}а добавляется локация "{ns}". Чтобы просматривать локацию, пользователь должен состоять в группе _{dv-notification-service-admins-dir}_.

.Локация "{ns}" для администраторов {ns}
image::notification-location.png[Локация "{ns}" для администраторов {ns}]

.Для администраторов {ns} локация предлагает следующие возможности:
* Создать xref:sending-card.adoc[Карточку рассылки].
* Создать xref:settings-card.adoc[Карточку уведомления].
* Посмотреть последние карточки уведомлений (по умолчанию `5` шт.) и перейти в папку с остальнынми карточками этого типа (кнопка `Ещё`).
* Посмотреть последние карточки рассылок (по умолчанию `5` шт.) и перейти в папку с остальнынми карточками этого типа (кнопка `Ещё`).
* Перейти в xref:directory-events.adoc[Справочник событий].
* Перейти в xref:directory-settings.adoc[Справочник настроек модуля].
* Перейти к поиску по xref:log.adoc[Журналу рассылки].

== Настройка уведомлений по событиям

Одним из способов настройки рассылки уведомлений является рассылка уведомлений при наступлении события. Для поддержки такого способа требуется сторонний процесс, генерирующий события рассылки и передающий информацию об объектах рассылки в сервис уведомлений.
Такой процесс может быть реализован для карточек любого типа, например, скриптом карточки или бизнес-процесса.

Для карточек типа _Задание_ существует стандартный процесс _{bo}_, отслеживающий события смены состояния задания. В справочнике событий уведомлений уже зарегистрированы события _Задание начато_ и _Задание завершено_ :

* _Задание начато_ -- к этому событию происходит обращение при переходе карточек типа Задание в состояние _Начато_.
* _Задание завершено_ -- к этому событию происходит обращение при переходе карточек типа _Задание_ в состояние _Завершено_.

.Чтобы настроить уведомление по событию, необходимо создать:
* Событие в справочнике событий, для которого будут формироваться уведомления;
* Карточки шаблона уведомления, по которым будут формироваться уведомления;
* Карточку рассылки, которая связывает событие и шаблоны.
