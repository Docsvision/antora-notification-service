= Рассылка уведомлений, сгенерированных в момент отсутствия лицензии

Модуль {ns} требует две опции лицензии:

** _{dv} 5 Сервис уведомлений. Настройка_.
+
Если лицензия на настройку отсутствует, при попытке открыть карточки модуля будет возникать ошибка, в журнал Службы {ws} будет записана ошибка `{dv} License does not contain feature "Notification Service. Customize`
+
** _{dv} 5 Сервис уведомлений. Рассылка_.
+
Если лицензия на рассылку отсутствует, рассылка уведомлений не будет выполняться, в журнал Службы {ws} будет записана ошибка `{dv} License does not contain feature "Notification Service. Sending`.

При отсутствии лицензии на рассылку уведомления будут генерироваться, но не будут отправляться: сообщение останутся в состянии `Пауза`:

.Сообщения в состоянии "Пауза"
image::no-license-pause.png[Сообщения в состоянии "Пауза]

Чтобы разослать эти уведомления, необходимо перевести их в состояние `Не обработано`. Для решения этой задачи предусмотрена специальная хранимая процедура.

[#launch-sending]
== Запустить рассылку

.Чтобы перевести сообщения в состояние "Не обработано":
. Вызовите процедуру из DVExplorer.
+
.Вызов процедуры из DVExplorer
image::no-license.png[Вызов процедуры из DVExplorer]
+
. В качестве `MessagesCardID` укажите идентификатор карточки сообщений, в которую сохраняются уведомления на рассылку.
+
.Идентификатор карточки сообщений определяется следующим образом:
.. В случае рассылки по событию:
... В DVExplorer откройте _Карточки сообщений_.
+
.Выбор карточки сообщений из DVExplorer
image::no-license-1.png[Выбор карточки сообщений из DVExplorer]
+
... Найдите карточку, содержащую `05c560d5-aa27-4e83-8f2d-b9b2651ce341` в описании.
... Нажмите на кнопку `Attributes`.
... Скопируйте `Card ID`.
+
.. В случае периодической рассылки:
... В DVExplorer откройте карточку рассылки.
... В секции "Основная информация" найдите параметр `ScheduleCardID` и скопируйте идентификатор карточки расписания.
+
.Копирование идентификатора карточки расписания из DVExplorer
image::no-license-2.png[Копирование идентификатора карточки расписания из DVExplorer]
+
... Найдите карточку расписания.
... В секции "Основная информация" найдите параметр `MessagesId` и скопируйте идентификатор карточки сообщений.
+
.Копирование идентификатора карточки сообщений из DVExplorer
image::no-license-2.png[Копирование идентификатора карточки сообщений из DVExplorer]
+
... Найдите карточку, содержащую `05c560d5-aa27-4e83-8f2d-b9b2651ce341` в описании.
... Нажмите на кнопку `Attributes`.
... Скопируйте `Card ID`.

. В параметрах `CreateDateFrom` и `CreateDateTo` укажите начало и конец периода времени, в который были сгенерированы уведомления.
+
NOTE: Не рекомендуется автоматически рассылать все сгенерированные, но не отправленные уведомления из-за их большого количества, а также неактуальных и тестовых уведомлений.
