= Карточка настроек уведомления

Карточка настроек уведомления (шаблон уведомления) содержит информацию, по которой формируется и отсылается уведомление. Информация будет получена на основании данных карточки. Обычно шаблон уведомления специфичен для каждого типа\вида карточки.

.Карточка настроек уведомления
image::settings-card.png[Карточка настроек уведомления]

.Чтобы создать новый шаблон уведомлений:
. Заполните поля карточки настройки уведомления:
+
* Основная информация:
** Название -- произвольное название карточки, определяющее её предназначение.
** Описание -- развёрнутое описание карточки, любые подробности, которые необходимы для работы с уведомлением.
* Настройки уведомления (значения из "xref:directory-settings.adoc[Справочника {nss}]":
** _Выберите компонент контекста данных из справочника_ -- компонент извлекает данные из карточки. Для неспецифичных задач можно использовать "Экспорт XML карточки со связанными 3 уровня". Компонент также отвечает за выбор файлов.
** _Выберите компонент преобразования из справочника_ -- компонент преобразует полученные из контекста данные в элементы уведомления. Для неспецифичных задач можно использовать "XSL-преобразование" или "Простой текст".
** _Выберите компонент отправки из справочника_ -- канал отправки уведомления, например, электронная почта.
** Добавлять основные файлы -- флаг определяет, будут ли к уведомлению приложены основные файлы.
** Добавлять дополнительные файлы -- флаг определяет, будут ли к уведомлению приложены дополнительные файлы.
* Настройки уведомления:
** На вкладках _Настройки темы_, _Настройки содержания_, _Настройки получателей_ можно выбрать отдельный компонент преобразования. Компонент будет применяться для извлечения темы, содержания или списка получателей из данных, полученных компонентом контекста. В текстовом поле "Компоненты преобразования для ..." можно указать дополнительные настройки, которые будет использовать общий или отдельный компонент преобразования.
** Настройки содержания -- выберите компонент преобразования содержания уведомления, настроенный в "xref:directory-settings.adoc[Справочнике {nss}]", можно использовать XSLT или простой текст.
* Детали уведомления:
** _Добавить к получателям_ -- дополнительные получатели, которые будут добавлены в рассылку. Выберите значение из справочника сотрудников/контрагентов или укажите текстовое значение. За определение канала уведомления для выбранного значения в адрес получателя отвечает компонент отправки.
** _Исключить получателей_ -- получатели, адреса которых будут исключены из рассылки. За определение канала уведомления для выбранного значения в адрес получателя отвечает компонент отправки. Исключение выполняется после сбора основных и дополнительных получателей.
+
.	Сохраните изменения в шаблоне нажатием кнопки *Сохранить*.
.	Используйте шаблон в xref:sending-card.adoc[Карточке рассылки].
