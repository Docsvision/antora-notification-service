= Справочник {nss}

Справочник поставляется в составе модуля _{ns}_. Справочник {nss} предназначен для хранения однотипных настроек, которые позже могут быть использованы в карточках настроек уведомления:

* Настройки компонент контекста данных уведомлений.
* Настройки компонент формирования уведомления.
* Настройки каналов отправки уведомлений.
* Настройки компонент обработки ответа на уведомление (опционально).

[#components]
== Настройки компонентов

Настройки компонент расположены на отдельных вкладках справочника. Нажмите на кнопку image:buttons/plus.png[Плюс], чтобы добавить компонент.

Вкладка "Сбор данных"::
Настройка Компонентов контекста данных. Компоненты применяются для извлечения данных из карточек DocsVision и представления этих данных в форме, независимой от контекста. Также отвечают за выбор основных и дополнительных файлов и могут формировать начальный список получателей.

Преобразование данных::
Настройка Компонентов преобразования данных. Компоненты применяются для преобразования данных, полученных из компонента контекста в элементы уведомления: заголовок, содержимое или адресатов. Результатом работы компонента является модель уведомления, сформированная для отправки.

Отправка уведомлений::
Настройка Компонентов отправки уведомлений. Компоненты применяются для отправки уведомления адресатам. Компонент отправки определяет адреса получателей, сопоставляет их с адресами в списке исключаемых, устраняет повторы. Также компонент отправки загружает файлы вложений из базы DocsVision и преобразует во вложения своего формата.

// Компоненты обработки ответа::
// Погут применяться для распознавания ответных сообщений вместо механизма BackOffice (завершение из почты).

Периодические: Источники данных::
Настройка Компонентов источника данных периодической рассылки. Компоненты применяются для формирования выборки для периодической рассылки. Результатом работы компонента является неупорядоченная коллекция карточек для рассылки.

Периодические: Постобработка::
Настройка Компонентов постобработки данных периодической рассылки. Компоненты могут применяться для группирования и систематизации коллекции, полученной от компонента источника данных. Каждая собранная таким образом группа будет обработана компонентом контекста данных независимо от других.

[#columns]
== Предназначение колонок

Настройки для разных компонентов схожи, на вкладках представлен набор текстовых полей:

Название:::
Произвольное наименование компонента, позволяющее его идентифицировать.

Описание:::
Текстовое описание компонента, поле предназначено для добавления подробного описания компонента.

Имя класса:::
Поле используется для указания класса реализации компонента. Указывается полное наименование класса.

Дополнительные настройки::
Дополнительные настройки, которые могут потребоваться при работе с компонентом.

Чтобы удалить компонент, нажмите на кнопку image:buttons/urn.png[Урна] в правой части строки.
