= Настройка расписания уведомлений

[#scheduled]
== Настройка рассылки уведомлений по расписанию

Кроме рассылки уведомлений непосредственно по событию в момент регистрации события, возможна настройка периодических уведомлений.

.Чтобы настроить периодическое событие, нужно создать:
* Карточку настроек рассылки с пометкой _Периодическая рассылка_.
* Карточки шаблонов уведомлений.

Создание шаблона уведомления для периодической рассылки незначительно отличается от создания шаблона для рассылки по событию, за исключением того, что используемые компоненты должны уметь работать с набором данных, а не одной карточкой.

[#periodic]
== Настройка периодичности рассылки уведомлений

.Карточка настроек рассылки уведомлений в режиме периодических уведомлений
image::sending-scheduled.png[Карточка настроек рассылки уведомлений в режиме периодических уведомлений]

. Чтобы настроить периодические уведомления:
. Установите флаг `*Периодические уведомления*`, если требуется настроить периодические уведомления.
+
NOTE: При установке флага `*Периодические уведомления*` поле выбора события становится недоступным.
+
. Для массовой рассылки уведомлений (четырёхзначные порядки) предусмотрен флаг `*Альтернативная рассылка сообщений*`. Установка флага ускоряет ресурсоёмкие этапы массовой рассылки. При обычных обстоятельствах флаг может дать обратный эффект, замедлить рассылку.
. Задайте настройки для поиска карточек, по которым будут разосланы уведомления:
+
// ** Список настроенных поисковых запросов.
** _Источник данных_ (обязательное поле) -- список зарегистрированных компонентов источника данных для сохранения карточки. Обязательно должен быть выбран поисковый запрос или компонент. Можно использовать как альтернативу атрибутивному поиску.
*** _Настройки источника_ -- полный текст или ID поискового запроса.
** _Постобработка данных_ -- список зарегистрированных компонентов постобработки (необязательное поле) -- компоненты, которые смогут обработать полученные результаты поиска, например, сгруппировать полученные задания по исполнителям.
*** _Настройки постобработки_ -- дополнительные параметры в текстовой форме, которые источник постобработки использует для своей работы.
+
. Укажите настройки расписания. Выберите периодичность отправки уведомлений при помощи взаимоисключающих переключателей групп полей *По дням*, *По неделям*, *По месяцам*:
+
** *По дням* -- в поле _Повторять каждые_ заполняется целым числом, если нужно отправлять уведомление каждый определённый день, например, Каждый `1` день, Каждый `2` день и так далее.
** *По неделям* -- если требуется отправка уведомления в определенный день недели, напротив соответствующего дня необходимо установить флаг. Позволяет настроить отправку уведомления каждую определённую неделю, заполнив поле _Повторять каждые_ целым числом. Например "Каждую `1` неделю", "Каждую `2` неделю" и так далее.
** *По месяцам* -- позволяет настроить отправку уведомления каждый определённый месяц.
+
--
*** Установите переключатель *В день недели* или *В число месяца*, чтобы выбирать число или день недели месяца, в который будет отправляться уведомление.
--
+
В поле _Каждого_ укажите целое число не более `12`, например, цифра `2` будет означать каждый второй месяц.
+
. Укажите настроки периодичности отправки уведомления в пределах одного дня в группе полей _Периодичность в день_. Установите один из переключателей:
+
** Однократно -- задайте время уведомления в заданый день.
** Повтор через X минут -- задайте периодичность уведомления, указав целое число минут.
** Повтор через X часов -- задайте периодичность уведомления, указав целое число минут.
+
. Укажите продолжительность рассылки:
+
** В поле _Дата начала_ укажите дату начала отправки уведомления (нельзя выбрать прошедшую дату).
** В поле _Дата завершения_ укажите дату окончания отправки уведомления.
** Если дата завершения уведомлений не определена, установите флаг `*Бесконечно*`. В таком случае поле _Дата завершения_ становится недоступным для изменения, а у уведомлений не будет даты завершения рассылки.
+
. Сохраните данные расписания нажатием кнопки *Сохранить*.
// Данные расписания будут записаны в _Карточку расписания_ после установки флага `*Активно*`.
// +
// После утановки флага редактирование распсиания становится недоступным, настройки расписания будут сохранены в связанной "Карточке настроек рассылки уведомления". Уведомления будут отправляться согласно настроенному расписанию. Если администратор удалит "Карточку настроек рассылки уведомлений", "Карточка расписания" также будет удалена.
