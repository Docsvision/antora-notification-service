= Карточка настроек рассылки уведомлений

Карточка настроек рассылки уведомлений связывает событие из справочника и xref:settings-card.adoc[Карточки настроек уведомления] (шаблоны уведомлений).

.Карточка настроек рассылки уведомлений
image::sending-card.png[Карточка настроек рассылки уведомлений]

.Чтобы создать новую карточку рассылки уведомлений:
. Заполните поля карточки настроек рассылки уведомлений:
+
* Основная информация:
** Название рассылки -- название карточки, отражающее суть рассылки.
** По умолчанию рассылка неактивна, администратор может ее включить при необходимости, установив флаг `*Активна*`.
* Ссылки -- ссылки на созданные карточки настроек уведомления.
+
.Добавление ссылки на карточку уведомления
image::add-link.png[Добавление ссылки на карточку уведомления]
+
При нажатии на кнопку image:buttons/plus.png[Плюс] и image:buttons/add-link.png[Добавить ссылку] открывается окно поиска ссылки на карточки настроек уведомления. При поиске можно указать тип искомого объекта и область поиска.
+
* При нажатии кнопки image:buttons/adjustments.png[Настройки] открывается окно настройки столбцов, позволяющее выбрать, какие столбцы будут отображаться в карточке при открытии её в режиме чтения.
+
.Настройка столбцов
image::sending-columns.png[Настройка столбцов]
+
* Способ активации:
** Флаг `*Периодические уведомления*` -- признак периодичности уведомления. При создании периодического уведомления поле выбора события скрывается, но появляются новые настройки, см. подробнее "xref:schedule.adoc[]".
+
** Выберите событие из "xref:directory-settings.adoc[Справочника {ne}]", для которого создаётся рассылка. Если событие не привязано ни к одной из карточек рассылки, по нему не будут формироваться уведомления.
+
