= DocsVision.NotificationService.ObjectModel.TaskRouting -- пространство имён

Пространство имён `DocsVision.NotificationService.ObjectModel.TaskRouting` содержит классы для интеграции системы уведомлений с маршрутизацией заданий. Обеспечивает обработку событий жизненного цикла задач и формирование контекста данных для отправки уведомлений по электронной почте.
