== Методы

[cols=",",options="header"]
|===
|Имя |Описание

|`CreateNotificationSettingsCard(KindsCardKind);`
a|Инициализирует карточку настроек уведомления

.Параметры:
* `kind` -- вид карточки

*Возвращаемое значение*: `xref:Entities/CardNotificationSettings/NotificationSettings_CL.adoc[NotificationSettings]` -- карточка настроек уведомления

|`CreateNotificationSendingSettingsCard(KindsCardKind);`
a|Инициализирует карточку настроек рассылки уведомлений

.Параметры:
* `kind` -- вид карточки

*Возвращаемое значение*: `xref:Entities/CardNotificationSettings/NotificationSettings_CL.adoc[NotificationSendingSettings]` -- карточка настроек рассылки уведомлений

|`CreateScheduleCard(Guid);`
a|Инициализирует карточку расписания

.Параметры:
* `parentCardId` -- ID родительской карточки

*Возвращаемое значение*: `xref:CardLib/CardDefs/CardSchedule_CL.adoc[CardSchedule]` -- карточка расписания

|`GetDataTransformFlags(Guid);`
a|Получает параметры компонента формирования модели уведомления

.Параметры:
* `componentID` -- идентификатор компонента

*Возвращаемое значение*: `xref:Models/NotificationDataTransformFlags_EN.adoc[NotificationDataTransformFlags]`
