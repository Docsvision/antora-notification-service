= Компоненты постобработки

TaskNotificationDataSourcePostHandler::
Соответствует компоненту постобработки данных _Задания с группировкой по исполнителям_.
+
Не использует дополнительные настройки в Справочнике {nss}.
+
Класс компонента фильтрует переданные ID по типу _Задание_ и распределяет их на группы по значениям _Текущих исполнителей_, возвращает непустые группы с ID карточек.
