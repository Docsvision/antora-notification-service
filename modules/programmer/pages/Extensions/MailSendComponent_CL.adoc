= MailSendComponent -- класс

Компонент отправки уведомлений через почту, должен вычитывать свои настройки через сервис настроек (настройки соединения с почтой). Может создавать шлюз Workflow к почте и инициализировать его этими настройками.

* *Пространство имён:* `DocsVision.NotificationService.ObjectModel.Extensions`
* *Сборка:* `DocsVision.NotificationService.ObjectModel.dll`

== Синтаксис

[source,csharp]
----
public class MailSendComponent : INotificationSendChannel, IInitializeWithSettings, IInitializeWithObjectContext
----
