= CardXmlExportDataContext -- класс

Базовый класс для контекста данных на базе карточек с экспортом карточки в XML

* *Пространство имён:* `DocsVision.NotificationService.ObjectModel.Extensions`
* *Сборка:* `DocsVision.NotificationService.ObjectModel.dll`

== Синтаксис

[source,csharp]
----
public abstract class CardXmlExportDataContext : INotificationObjectDataContext, IInitializeWithObjectContext
----

== Конструкторы

[cols=",",options="header"]
|===
|Имя |Описание

|`CardXmlExportDataContext()`
|Инициализирует новый экземпляр класса `CardXmlExportDataContext`. Инициализация компонента необходима при использовании конструктора без параметров.

|`CardXmlExportDataContext(ObjectContext, NotificationSettings)`
a|Инициализирует новый экземпляр класса `CardXmlExportDataContext` с указанными свойствами

.Параметры:
* `context` -- контекст объекта
* `xref:Entities/CardNotificationSettings/NotificationSettings_CL.adoc[settings]` -- настройки уведомления

|===
