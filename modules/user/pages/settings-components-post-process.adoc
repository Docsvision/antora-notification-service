= Компоненты постобработки

Компоненты постобработки применяются для обработки коллекции источников данных, полученных от компонента источника. Эти компоненты используются в периодических рассылках, однако их применение не обязательно, в отличие от компонента источника данных.

[#group]
Задания с группировкой по исполнителям::
Не использует дополнительные настройки в Справочнике {nss}.
+
Компонент фильтрует переданные ID по типу _Задание_ и распределяет их на группы по значениям Текущих исполнителей, возвращает непустые группы с ID карточек.
