= Рассылка по событию

Одним из способов настройки рассылки уведомлений является рассылка уведомлений при наступлении события.

Для рассылки уведомлений по событию требуется сторонний процесс, генерирующий события рассылки и передающий информацию об объектах рассылки в сервис уведомлений.

Такой процесс может быть реализован для карточек любого типа, например, скриптом карточки или бизнес-процессом.

Для карточек типа _Задание_ существует стандартный процесс _{bo}_, отслеживающий события смены состояния задания. В справочнике событий уведомлений уже зарегистрированы события _Задание начато_, _Задание завершено_, _Задание на приёмке_ и _Задание на доработке_:

* _Задание начато_ -- к этому событию происходит обращение при переходе.
карточек типа Задание в состояние Начато.
* _Задание завершено_ -- к этому событию происходит обращение при переходе.
карточек типа Задание в состояние Завершено
* _Задание на приёмке_ -- к этому событию происходит обращение при переходе карточек типа Задание в состояние _На приёмке_.
* _Задание на доработке_ -- к этому событию происходит обращение при переходе карточек типа _Задание_ в состояние _На доработке_.

== Создание уведомления по событию

Чтобы {ns} обработал событие, необходимы карточки рассылки, подписанные на это событие. Карточки рассылки при этом не могут быть в режиме "Периодическая".

. В поле _Событие_ выберите событие из "xref:settings-dir.adoc[Справочника {ne}]", для которого создаётся рассылка. Если событие не привязано ни к одной из карточек рассылки, по нему не будут формироваться уведомления.
+
На одно событие может быть подписано несколько карточек рассылки, но рекомендуется сохранять одну активную карточку рассылки.
+
.Выбор события из справочника событий уведомлений
image::select-event.png[Выбор события из справочника событий уведомлений]
+
.Создание рассылки по событию
image::by-event.png[Создание рассылки по событию]
+
. При необходимости в поле _Ссылки_ укажите одну или несколько карточек настроек уведомлений. Любая карточка настроек может использоваться в нескольких карточках рассылки.
+
. После завершения редактирования карточки рассылки установите флаг `*Активна*`, чтобы активировать рассылку.
