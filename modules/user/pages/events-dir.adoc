= Работа со справочником событий

Справочник событий содержит структуру известных событий карточек, которые можно использовать для привязки в карточках настроек рассылки по событию. При регистрации события рекомендуется указывать идентификатор известного события, а не только источник уведомления, чтобы устранить неопределённость.

.Справочник {ne}
image::events-dir.png[Справочник {ne}]

В справочник можно добавить новые известные события.

.Для каждого необходимо указать:
* _Идентификатор_ -- уникальный идентификатор в рамках текущей карточки.
* _Название_ -- отображаемое название события.
* _Тип карточки_ -- идентификатор типа карточки, для которого данное событие имеет смысл.

.Дополнительно можно указать:
* _Описание_ -- опциональное описание события.
* _Вид карточки_ -- вид карточки, для которого это событие может быть исполнено. Это поле используется в случае, если сервисом получено неопределённое событие.
* _Состояние карточки_ -- состояние карточки указанного вида, для которого это событие может быть исполнено. Это поле используется в случае, если сервисом получено неопределённое событие.
