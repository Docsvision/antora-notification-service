= Работа со справочником настроек

Справочник {nss} содержит компоненты или логические модули, которые могут использоваться сервисом уведомлений в процессе формирования или отправки уведомлений. Записи из справочника могут быть выбраны в карточках рассылки или карточках настроек уведомлений. Заполнением справочника занимается разработчик дополнительных модулей.

.Справочник {nss}
image::settings-dir.png[Справочник {nss}]

.Для каждой записи есть следующие поля:
* _Название_ -- отображаемое название компонента
* _Описание_ -- дополнительное описание модуля
* _Имя класса_ -- полное имя класса реализации компонента
* _Дополнительные настройки_ -- дополнительные параметры в строковом виде.

Подробнее о добавлении компонентов см. в разделе "xref:programmer:add-extensions.adoc[Создание дополнительных расширений]" руководства разработчика.

== Базовые компоненты справочника настроек

Компоненты распределены по вкладкам исходя из их предназначения.

.Следующие компоненты включены в базовую версию модуля для упрощения эксплуатации:
* Компоненты сбора (контекста) данных
* Компоненты преобразования данных
* Компоненты отправки уведомлений (каналы рассылки)
* Компоненты обработки ответа
* Компоненты источников данных для периодических рассылок
* Компоненты постобработки данных для периодических рассылок
