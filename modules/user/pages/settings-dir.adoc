= Справочник {nss}

Справочник используется для регистрации компонентов, применяемых в карточках рассылки и настройки уведомлений. По месту применения компоненты разделены на группы.

Записи из справочника могут быть выбраны в карточках рассылки или карточках настроек уведомлений. Заполнением справочника занимается разработчик дополнительных модулей.

[#components]
== Настройки компонентов

Настройки компонентов расположены на отдельных вкладках справочника. Нажмите на кнопку image:buttons/plus.png[Плюс], чтобы добавить компонент.

Чтобы удалить компонент, нажмите на кнопку image:buttons/urn.png[Урна] в правой части строки.

Вкладка "Сбор данных"::
Настройка "xref:settings-components-context.adoc[Компонентов контекста данных]". Компоненты применяются для извлечения данных из карточек {dv} и представления этих данных в форме, независимой от контекста. Также отвечают за выбор основных и дополнительных файлов и могут формировать начальный список получателей.

Вкладка "Преобразование данных"::
Настройка "xref:settings-components-transform.adoc[Компонентов преобразования данных]". Компоненты применяются для преобразования данных, полученных из компонента контекста в элементы уведомления: заголовок, содержимое или адресатов. Результатом работы компонента является модель уведомления, сформированная для отправки.

Вкладка "Отправка уведомлений"::
Настройка "xref:settings-components-send.adoc[Компонентов отправки уведомлений]". Компоненты применяются для отправки уведомления адресатам. Компонент отправки определяет адреса получателей, сопоставляет их с адресами в списке исключаемых, устраняет повторы. Также компонент отправки загружает файлы вложений из базы {dv} и преобразует во вложения своего формата.

// Компоненты обработки ответа::
// Погут применяться для распознавания ответных сообщений вместо механизма BackOffice (завершение из почты).

Вкладка "Периодические: Источники данных"::
Настройка "xref:settings-components-source.adoc[Компонентов источника данных]" периодической рассылки. Компоненты применяются для формирования выборки для периодической рассылки. Результатом работы компонента является неупорядоченная коллекция карточек для рассылки.

Вкладка "Периодические: Постобработка"::
Настройка "xref:settings-components-post-process.adoc[Компонентов постобработки данных]" периодической рассылки. Компоненты могут применяться для группирования и систематизации коллекции, полученной от компонента источника данных. Каждая собранная таким образом группа будет обработана компонентом контекста данных независимо от других.

[#columns]
== Предназначение колонок

Настройки для разных компонентов схожи, на вкладках представлен набор текстовых полей:

Название:::
Произвольное наименование компонента, позволяющее его идентифицировать.

Описание:::
Текстовое описание компонента, поле предназначено для добавления подробного описания компонента.

Имя класса:::
Поле используется для указания класса реализации компонента. Указывается полное наименование класса.

Дополнительные настройки::
Дополнительные настройки, которые могут потребоваться при работе с компонентом.

[#std-components]
== Стандартные компоненты в поставке

.Следующие компоненты включены в базовую версию модуля:
* "xref:settings-components-context.adoc#l3[Экспорт XML карточки со связанными 3 уровня]" -- компонент контекста данных, возвращающий строковое представление XML карточки, связанных с ней карточек до уровня вложенности 3 и используемых данных справочников. Может использоваться для группы карточек, в этом случае результат содержит упорядоченные данные всех карточек. Дополнительные настройки при инициализации этого компонента неприменимы.
* "xref:settings-components-transform.adoc#xslt[XSL-преобразование]" -- компонент преобразования данных, применяющий XSL-преобразование на входной поток, и возвращающий результат. Текст преобразования необходимо передавать при помощи полей _Настройки компонента преобразования_ в "xref:settings-card.adoc[карточке настроек]".
* "xref:settings-components-transform.adoc#text[Простой текст]" -- компонент преобразования данных, возвращающий переданный в него текст без изменения. Текст необходимо передавать при помощи полей _Настройки компонента преобразования_ в xref:settings-card.adoc[карточке настроек].
* "xref:settings-components-send.adoc#email[Электронная почта]" -- компонент отправки, использующий механизм отправки электронной почты модуля {bo}. Может использоваться для отправки HTML-сообщений, принимает в качестве вложений файлы системы {dv}. Определяет адреса получателей как email сотрудников, выбирает сотрудников из подразделений или групп. Также принимает корректный адрес электронной почты в строковом виде в качестве адресата.
* "xref:settings-components-source.adoc#search-card[Поиск карточек]" -- компонент источника данных, возвращающий результат поискового запроса. Полный текст или ID поискового запроса нужно передать в качестве параметра через поле _Настройки источника_. Принимает только корректные поисковые запросы {dv}.
* "xref:settings-components-post-process.adoc#group[Задания с группировкой по исполнителям]" -- компонент постобработки данных, разделяющий список заданий на группы по текущему исполнителю. Карточки, не являющиеся заданиями, исключаются из результата.
* "xref:settings-components-send.adoc#ntf-sms[МТС-Маркетолог СМС]" -- компонент отправки, использующий API внешнего сервиса "МТС-Маркетолог" для отправки СМС-сообщений. Для работы компонента требуется аккаунт доступа к API с активным пакетом SMS. Данные аккаунта и адреса доступа, а также другие настройки передаются компоненту в строке настроек.
