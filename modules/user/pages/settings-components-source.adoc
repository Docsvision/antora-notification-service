= Компоненты источника данных

Поиск просроченных заданий::
Не использует дополнительные настройки в Справочнике {nss}.
+
Класс компонента осуществляет поиск просроченных заданий встроенным запросом, возвращает список ID найденных карточек.

Поиск карточек::
Требует дополнительные настройки (справочник настроек) при инициализации в виде XML запроса {dv} или ID существующего сохранённого запроса.
+
Класс компонента выполняет переданный в параметре поисковый запрос, возвращает список ID найденных карточек.
