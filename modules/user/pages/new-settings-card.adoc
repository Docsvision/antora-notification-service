= Настройка шаблона уведомления

Карточка настроек уведомления, или шаблон уведомления, содержит настройки, необходимые для построения и отправки сообщения.

В первом блоке указывается отображаемое название шаблона. Описание опционально.

== Настройки уведомления

Настройки уведомления определяют, как будет сформирована первичная модель уведомления. Из справочника следует выбрать компонент контекста данных, преобразования и отправки.

Компонент контекста данных служит для извлечения данных в каком-то виде из источника уведомления, т.е. карточки или группы карточек. Например, _Экспорт XML_ возвращает xml карточки со связанными в виде текста. Если источником является группа карточек, они последовательно добавляются к xml.

Компонент преобразования используется для формирования элементов уведомления из модели данных, возвращаемой компонентом контекста. Компонент преобразования должен быть совместим с этой моделью данных. Например, _XSL-преобразование_ совместимо с экспортом XML.

Компонент отправки выполняет отправку готового уведомления. Также компонент отправки содержит собственную логику преобразования получателей в адресаты, формирование вложений если они допустимы и др.

Флаги `*Добавлять основные\дополнительные файлы*` используются для сохранения в первичной модели вложений, помеченных как основные\дополнительные. Снимите флаг чтобы удалить соответствующие вложения.

== Детали уведомления

Дополнительные настройки уведомления: темы, содержания и получателей, позволяют выбрать отдельный компонент преобразования для конкретного элемента при необходимости и задать значение параметра настроек, используемого для получения значения этого элемента. Выбор компонента преобразования здесь не обязателен (не рекомендуется выбирать тот же компонент, который уже задан в основных настройках). Ниже расположено поле для значения параметра настроек. Например, для XSL-преобразования значением параметра будет являться текст XSLT, позволяющий получить из XML нужную строку для темы, или текст содержания, или список адресатов.

== Дополнительные получатели

Блок настройки получателей используется для безусловного добавления адресатов или исключения некоторых адресатов из списка, если они были выбраны компонентом преобразования. Формированием итогового списка адресатов занимается компонент отправки. Например, если в таблице _Добавить_ выбрать отдельного сотрудника, а в таблице _Исключить_ ввести его e-mail, то компонент отправки _Электронная почта_ вычислит адрес сотрудника и исключит его из списка. Другой пример, если сотрудник выбран компонентом преобразования и в таблице _Добавить_ указано его же подразделение, компонент отправки _Электронная почта_ обнаружит повтор и не включит адрес в список дважды.
