= Рассылка по расписанию

Кроме рассылки уведомлений непосредственно по событию в момент регистрации события, возможна настройка периодических уведомлений.

.Чтобы настроить периодическое событие, нужно создать:
* Карточку настроек рассылки с пометкой _Периодическая рассылка_.
* Карточки шаблонов уведомлений.

Создание шаблона уведомления для периодической рассылки незначительно отличается от создания шаблона для рассылки по событию, за исключением того, что используемые компоненты должны уметь работать с набором данных, а не одной карточкой.

.Карточка настроек рассылки уведомлений в режиме периодических уведомлений
image::sending-schedule.png[Карточка настроек рассылки уведомлений в режиме периодических уведомлений]

Дополнительно можно изменить порядок формирования уведомлений, установив флаг `*Альтернативная рассылка сообщений*`.

NOTE: Рекомендуется использовать альтернативную рассылку сообщений только в случае, когда обработка периодической рассылки создаёт большую нагрузку на систему.

== Создание рассылки по расписанию

.Чтобы настроить периодические уведомления:
. Укажите название карточки, отражающее суть рассылки в поле _Название рассылки_.
. По умолчанию рассылка неактивна, после выполнения всех настроек администратор может активировать рассылку, установив флаг `*Активна*`.
. В поле _Ссылки_ можно указать одну или несколько карточек настроек уведомлений. Любая карточка настроек может использоваться в нескольких карточках рассылки.
. Установите флаг `*Периодические уведомления*`, если требуется настроить периодические уведомления.
+
NOTE: При установке флага `*Периодические уведомления*` поле выбора события становится недоступным.
+
. Для массовой рассылки уведомлений (четырёхзначные порядки) предусмотрен флаг `*Альтернативная рассылка сообщений*`. Установка флага ускоряет ресурсоёмкие этапы массовой рассылки. При обычных обстоятельствах флаг может дать обратный эффект, замедлить рассылку.
. Задайте "Основные настройки" расписания для поиска карточек, по которым будут разосланы уведомления:
+
.Основные настройки расписания
image::sending-general.png[Основные настройки]
+
** _Источник данных_ (обязательное поле) -- список зарегистрированных компонентов источника данных для сохранения карточки. Обязательно должен быть выбран поисковый запрос или компонент. Можно использовать как альтернативу атрибутивному поиску.
+
Собственные компоненты источника данных перед использованием в карточках необходимо добавить в Справочник {nss} на вкладке _Периодические: Источники данных_.
+
.Вкладка "Периодические: Источники данных" в Справочнике {nss}
image::setting-dir-sources.png[Периодические: Источники данных]
+
*** _Настройки источника_ -- полный текст или ID поискового запроса.
** _Постобработка данных_ -- список зарегистрированных компонентов постобработки (необязательное поле) -- компоненты, которые смогут обработать полученные результаты поиска, например, сгруппировать полученные задания по исполнителям.
+
Если компонент постобработки не выбран, все выбранные объекты будут обработаны как единая группа (будет сформировано одно уведомление по всем объектам).
Если выбранный компонент использует строковый параметр при работе, значение параметра нужно указать в строковом поле ниже.
+
Собственные компоненты постобработки данных перед использованием в карточках необходимо добавить в Справочник {nss} на вкладке _Периодические: Постобработка_.
+
.Вкладка "Периодические: Постобработка" в Справочнике {nss}
image::settings-dir-post.png[Периодические: Постобработка]
+
*** _Настройки постобработки_ -- дополнительные параметры в текстовой форме, которые источник постобработки использует для своей работы.
+
. Укажите настройки расписания в блоке "Расписание". Выберите периодичность отправки уведомлений при помощи взаимоисключающих переключателей групп полей *По дням*, *По неделям*, *По месяцам*:
+
** *По дням* -- в поле _Повторять каждые_ заполняется целым числом, если нужно отправлять уведомление каждый определённый день, например, Каждый `1` день, Каждый `2` день и так далее. Выходные и рабочие дни при этом не разделяются.
+
.Расписание по дням
image::sending-schedule-days.png[Расписание по дням]
+
** *По неделям* -- если требуется отправка уведомления в определенный день недели, напротив соответствующего дня необходимо установить флаг. Позволяет настроить отправку уведомления каждую определённую неделю, заполнив поле _Повторять каждые_ целым числом. Например "Каждую `1` неделю", "Каждую `2` неделю" и так далее.
+
.Расписание по неделям
image::sending-schedule-weeks.png[Расписание по неделям]
+
** *По месяцам* -- позволяет настроить отправку уведомления каждый определённый месяц. При данном типе периода разрешается выбрать только `1` день в месяце: указать число месяца, или выбрать день одной из недель (например, первый понедельник месяца).
+
.Расписание по месяцам
image::sending-schedule-months.png[Расписание по месяцам]
+
--
*** Установите переключатель *В день недели* или *В число месяца*, чтобы выбирать число или день недели месяца, в который будет отправляться уведомление.
--
+
В поле _Каждого_ укажите целое число не более `12`, например, цифра `2` будет означать каждый второй месяц.
+
. Укажите настройки периодичности отправки уведомления в пределах одного дня в блоке _Периодичность в день_. Установите один из переключателей:
+
.Блок "Периодичность в день"
image::sending-schedule-periodic.png[Блок "Периодичность в день"]
+
** Однократно -- задайте время уведомления в заданный день.
** Повтор через X минут -- задайте периодичность уведомления, указав целое число минут.
** Повтор через X часов -- задайте периодичность уведомления в минутах/часах, а также время суток начала и завершения повтора рассылки. Например, если указать `каждые 2 часа с 2:30 до 8:00`, рассылка будет выполняться в 2:30, 4:30, 6:30.
+
. Укажите "Продолжительность" рассылки. В блоке можно назначить дату начала и завершения действия текущего расписания. Например, если рассылку следует начать не сегодня или нужно автоматически прекратить в какой-то день.
+
.Блок "Продолжительность"
image::sending-schedule-duration.png[Блоке "Продолжительность"]
+
** В поле _Дата начала_ укажите дату начала отправки уведомления (нельзя выбрать прошедшую дату).
** В поле _Дата завершения_ укажите дату окончания отправки уведомления.
** Если дата завершения уведомлений не определена, установите флаг `*Бесконечно*`. В таком случае поле _Дата завершения_ становится недоступным для изменения, а у уведомлений не будет даты завершения рассылки.
+
. Сохраните данные расписания нажатием кнопки *Сохранить*.
