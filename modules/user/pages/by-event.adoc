= Создание рассылки по событию

Чтобы {ns} отработал событие, необходимы карточки рассылки, подписанные на это событие. Карточки рассылки при этом не могут быть в режиме "Периодическая".

Для подписки карточки рассылки нужно в поле _Событие_ выбрать соответствующую запись из справочника событий уведомлений. На одно событие может быть подписано несколько карточек рассылки, но рекомендуется сохранять одну активную карточку рассылки.

.Создание рассылки по событию
image:::by-event.png[Создание рассылки по событию]

В поле _Ссылки_ можно указать одну или несколько карточек настроек уведомлений. Любая карточка настроек может использоваться в нескольких карточках рассылки.

После завершения редактирования карточки рассылки следует установить флаг `*Активна*`, иначе эта рассылка будет проигнорирована.
