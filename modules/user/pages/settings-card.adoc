= Карточка настроек уведомления

Карточка настроек уведомления (шаблон уведомления) содержит компоненты и их настройки, используемые для формирования и отправки уведомления. Обычно шаблон уведомления специфичен для каждого типа\вида карточки.

.Карточка настроек уведомления
image::settings-card.png[Карточка настроек уведомления]

== Создание новой карточки настроек уведомления

.Чтобы создать новый шаблон уведомлений:
. Заполните поля в блоке _Основная информация_:
+
.Основная информация об уведомлении
image::settings-description.png[Основная информация об уведомлении]
+
** Название -- произвольное название карточки, определяющее её предназначение.
** Описание -- развёрнутое описание карточки, любые подробности, которые будут полезны для пользователей, выполняющих настройку уведомлений. Опциональное поле.
+
. В блоке _Настройки уведомления_ выберите компоненты контекста данных, преобразования и отправки (значения из "xref:settings-dir.adoc[Справочника {nss}]"):
+
.Блок "Настройки уведомления"
image::settings-general.png[Блок "Настройки уведомления]
+
** _Выберите компонент контекста данных из справочника_ -- компонент извлекает данные из карточки. Для большинства задач подходит "Экспорт XML карточки со связанными 3 уровня", возвращающий XML карточки со связанными в виде текста. Если источником является группа карточек, они последовательно добавляются к XML. Компонент также отвечает за выбор файлов.
+
** _Выберите компонент преобразования из справочника_ -- компонент преобразует полученные из контекста данные в элементы уведомления. Для большинства задач подходит "XSL-преобразование" или "Простой текст".
+
Компонент преобразования должен быть совместим с моделью данных контекста. Например, _XSL-преобразование_ должно быть совместимо с экспортом XML.
+
** _Выберите компонент отправки из справочника_ -- канал отправки уведомления, например, электронная почта.
+
Также компонент отправки содержит собственную логику преобразования получателей в адресаты, формирование вложений если они допустимы и др.
+
. Установите флаги `*Добавлять основные\дополнительные файлы*`, чтобы сохранить вложения. Снимите флаги, чтобы удалить соответствующие вложения.
+
** `*Добавлять основные файлы*` -- флаг определяет, будут ли к уведомлению приложены основные файлы.
** `*Добавлять дополнительные файлы*` -- флаг определяет, будут ли к уведомлению приложены дополнительные файлы.
+
. В блоке _Детали уведомления_ укажите дополнительные настройки уведомления:
+
.Блок "Детали уведомления"
image::settings-details.png[Блок "Детали уведомления]
+
** На вкладках _Настройки темы_, _Настройки содержания_, _Настройки получателей_ можно выбрать отдельный компонент преобразования. Компонент будет применяться для извлечения темы, содержания или списка получателей из данных, полученных компонентом контекста.
+
** В текстовом поле _Компоненты преобразования для ..._ указываются дополнительные настройки, которые будут использоваться общим или отдельным (если он указан) компонентом преобразования.
+
Например, для XSL-преобразования значением параметра будет являться текст XSLT, позволяющий получить из XML нужную строку для темы, текст содержания или список адресатов.
+
Выбор отдельного компонента преобразования не является обязательным, в частности, не рекомендуется выбирать тот же компонент, который уже задан в основных настройках.
+
. Блок _Добавить к получателям_ используется для добавления дополнительных адресатов. Блок _Исключить из получателей_ позволяет исключить получателей, если они были выбраны компонентом преобразования.
+
.Блок настройки получателей
image::settings-adressees.png[Блок настройки получателей]
+
--
** _Добавить к получателям_ -- дополнительные получатели, которые будут добавлены в рассылку. Выберите значение из справочника сотрудников/контрагентов или укажите текстовое значение. За преобразование уведомления для выбранного значения в адрес получателя отвечает компонент отправки.
** _Исключить получателей_ -- получатели, адреса которых будут исключены из рассылки. За преобразование уведомления для выбранного значения в адрес получателя отвечает компонент отправки. Исключение выполняется после сбора основных и дополнительных получателей.
--
+
Например, если в блоке _Добавить к получателям_ выбрать отдельного сотрудника, а в таблице _Исключить получателей_ ввести его e-mail, компонент отправки _Электронная почта_ вычислит адрес сотрудника и исключит его из списка.
+
В случае если сотрудник выбран компонентом преобразования и в таблице _Добавить к получателям_ указано его же подразделение, компонент отправки _Электронная почта_ обнаружит повтор и не включит адрес в список дважды.
+
.	Сохраните изменения в шаблоне нажатием кнопки *Сохранить*.
.	Используйте шаблон в xref:sending-card.adoc[Карточке рассылки].
