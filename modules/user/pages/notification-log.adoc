= Журнал рассылки уведомлений

В журнале рассылки уведомлений фиксируется момент и результат отправки стандартных и специальных уведомления.

Жернал представляет собой папку и представление _Поиск по журналу_ с настроенным параметрическим поиском.

. В главном меню {wc}а выберите папку, появится окно для выбора параметров запроса.
+
.Выбор параметров запроса для папки "Поиск по журналу"
image::parameters.png[Выбор параметров запроса папки "Поиск по журналу"]
+
.Параметры поиска:
--
* _Получатель_ -- выберите сотрудника.
* _День от_ -- укажите дату начала периода.
* _до_ -- укажите дату окончания периода.
--
+
Поля могут быть активированы или отключены при помощи переключателей в правом конце строки.
+
. Нажмите *ОК*. После нажатия кнопки будет открыто представление _Поиск по журналу_, в котором каждая строка грида является отдельным уведомлением. В гриде отображаются только основные поля карточки журнала уведомлений, поэтому для просмотра детальной информации по строке журнала необходимго открыть карточку рассылки уведомления.
+
.Пример грида со строками журнала рассылки
image::grid-log.png[Пример грида со строками журнала рассылки]
+
. Откройте карточку нажатием левой кнопки мыши на интересующую строку журнала, либо выберите операцию открытия из контекстного меню строки грида.
+
.Пример отображения конкретной строки журнала рассылки
image::grid-log-line.png[Пример отображения конкретной строки журнала рассылки]
+
. URL журнала формируется по следующему принципу: `\http://адрес-сервера-Web-клиента/DocsvisionWebClient/#/RowView/%cardId%/%sectionId%/%rowId%`, где:
+
* `%cardId%` -- идентификатор карточки `CardNotificationLog`.
* `%sectionId%` -- идентификатор секции `LogSectionID`.
* `%rowId%` -- идентификатор открываемой строки журнала.

// NOTE: На текущий момент {kvr} позволяет настраивать разметки только для строк справочников, но не карточек. Поэтому перед настройкой разметки временно необходимо для `CardNotificationLog` выставить флаг `*Dictionary (only one instance allowed)*`. У конечных пользователей настроенная разметка не будет отображаться в программе {kvr}, но должна открываться на просмотр в {wc}е.
