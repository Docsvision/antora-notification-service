= Компоненты отправки уведомления

Компоненты отправки предназначены для доставки уведомления получателю. Компонент отправки интерпретирует экземпляр уведомления, определяет, какие элементы ему использовать каким образом,реализует доставку в собственных терминах. Входящие в базовую поставку компоненты оставляют записи об успешности отправки в Карточке журнала уведомлений.

[#email]
Электронная почта::
Не использует дополнительные настройки в Справочнике {nss}, но требует лицензию и отключение стандартных уведомлений, см. подробнее <<ntf-mail,ниже>>.
+
--
.Адреса получателей определяются в зависимости от их типа следующим образом:
* _Подразделение_, _Группа_ или _Роль_ -- выбирает адреса всех сотрудников, входящих в данный объект.
* _Сотрудник_ или _Сотрудник контрагента_ -- получает значение из поля Email.
* _Простое значение_ -- использует переданный текст в качестве адреса.
--
+
Для всех собранных адресов проверяется соответствие строки общепринятому формату адреса электронной почты.

МТС-Маркетолог СМС::
Требует <<ntf-sms,дополнительные настройки>> в Справочнике {nss}. Класс компонента использует тело сообщения в качестве отправляемого сообщения, ограничивая его размер в соответствии с настройками.
+
--
.Адреса получателей определяются в зависимости от их типа следующим образом:
* _Подразделение_ -- получает значение из поля Phone.
* _Сотрудник_ или _Сотрудник контрагента_ -- получает значение из поля `MobilePhone`.
* _Простое значение_ -- использует переданный текст в качестве адреса.
--
+
См. пример настройки компонента "МТС-Маркетолог СМС" в справочнике настроек по ссылке: xref:attachment$sms.xsl[sms.xsl].

[#ntf-mail]
== Работа с почтовыми уведомлениями {of-ns}

Пользователь может выполнять задания из почтового уведомления. В этом случае исполнителю задания будут поступать письма, содержащие описание задания и кнопки завершения. Для завершения задания можно использовать как почтовую программу, так и стандартный "клиент" {dv}.

Выполнение заданий в почтовом клиенте, описано в документации модуля {bo}, см. "xref:backoffice:user:mail-client/description.adoc[]". Тип маршрутизации, настроенный на уровне самого задания или исполнителя, должен быть _Задача почтового клиента_.

NOTE: Для выполнения заданий из почтового уведомления потребуется опция лицензии _{dv} Outlook Client_. В противном случае письма будут формироваться без кнопок, а в журнал Службы {ws} будет записываться ошибка `{dv} License does not contains {dv} Outlook Client`.

[#disable-standard]
== Отключение стандартных почтовых уведомлений

{ns} формирует уведомления, которые могут дублироваться стандартными. Чтобы избежать дублирования, рекомендуется отключить уведомления.

.Отключить стандартные уведомления можно следующим образом:
. В DVExplorer откройте справочник видов.
. Откройте секцию корневого вида "Задание".
. У сервиса `DocsVision.BackOffice.TaskRouting.Services.TRTaskMessagesEventHandlerService` в свойстве `Disabled` задайте значение `True`.
+

[#ntf-sms]
== Настройка СМС-уведомлений

. Создайте бизнес-аккаунт в сервисе МТС-Маркетолог и настройте интеграцию API.
. В {wc}е откройте Справочник {nss} и перейдите на вкладку _Отправка уведомлений_.
. Для компонента рассылки _МТС-Маркетолог СМС_ в поле _Дополнительные настройки_ укажите данные для входа в сервис. Данные необходимо указывать в параметрах `<Login>Username</Login>` и `<Password>P@ssw0rd</Password>`.
. Назначьте компонент в xref:settings-card.adoc[Карточке настроек уведомления], привязанной к требуемой xref:sending-card.adoc[Карточке настроек рассылки уведомлений].
+
К рассылке может быть привязано одновременно несколько карточек настроек для создания разных уведомлений (почта, смс) по событию рассылки.
+
.Настройка СМС уведомлений в Карточке настроек уведомления
image::sms-notification.png[Настройка СМС уведомлений в Карточке настроек уведомления]
+
Номер для СМС уведомления можно указать напрямую, добавив получателя типа _Простое значение_. Если получатель указывается как сотрудник или подразделение, номер следует указать в поле «Мобильный телефон» в настройках сотрудника\подразделения.
+
NOTE: Указывайте номер в формате 11 цифр без других символов, начиная с 7 или 8. Например, `79213456780`.
