= Карточка настроек рассылки уведомлений

Одним из способов настройки рассылки уведомлений является рассылка уведомлений при наступлении события.

Карточка настроек рассылки уведомлений связывает событие из справочника и "xref:settings-card.adoc[Карточки настроек уведомления]" (шаблоны уведомлений).

.Карточка настроек рассылки уведомлений
image::sending-card.png[Карточка настроек рассылки уведомлений]

Для рассылки уведомлений по событию требуется сторонний процесс, генерирующий события рассылки и передающий информацию об объектах рассылки в сервис уведомлений.

Такой процесс может быть реализован для карточек любого типа, например, скриптом карточки или бизнес-процессом.

Для карточек типа _Задание_ существует стандартный процесс _{bo}_, отслеживающий события смены состояния задания. В справочнике событий уведомлений уже зарегистрированы события _Задание на приёмке_ и _Задание на доработке_:

* _Задание на приёмке_ -- к этому событию происходит обращение при переходе карточек типа Задание в состояние _На приёмке_.
* _Задание на доработке_ -- к этому событию происходит обращение при переходе карточек типа _Задание_ в состояние _На доработке_.

.Чтобы настроить уведомление по событию, необходимо создать:
* Событие в справочнике событий, для которого будут формироваться уведомления;
* Карточки шаблона уведомления, по которым будут формироваться уведомления;
* Карточку рассылки, которая связывает событие и шаблоны.

[#fields]
== Поля карточки

.Карточка рассылки уведомлений имеет следующие поля:
. Блок "Основная информация":
+
** Название рассылки -- название карточки, отражающее суть рассылки.
** По умолчанию рассылка неактивна, администратор может ее включить при необходимости, установив флаг `*Активна*`.
. Блок "Ссылки" -- ссылки на созданные карточки настроек уведомления.
+
.Ссылки на карточку уведомления
image::add-link.png[Сссылки на карточку уведомления]
+
При нажатии кнопок image:buttons/plus.png[Плюс] и image:buttons/add-link.png[Добавить ссылку] открывается окно поиска ссылки на карточки настроек уведомления. При поиске можно указать тип искомого объекта и область поиска.
+
* При нажатии кнопки image:buttons/adjustments.png[Настройки] открывается окно настройки столбцов, позволяющее выбрать, какие столбцы будут отображаться в карточке при открытии её в режиме чтения.
+
.Настройка столбцов
image::sending-columns.png[Настройка столбцов]
+
. Блок "Способ активации":
+
** Флаг `*Периодические уведомления*` -- признак периодичности уведомления. Для периодического уведомления поле выбора события скрывается, но появляются новые настройки, см. подробнее "xref:on-schedule.adoc[]".
+
** Выберите событие из "xref:settings-dir.adoc[Справочника {ne}]", для которого создаётся рассылка. Если событие не привязано ни к одной из карточек рассылки, по нему не будут формироваться уведомления.
+
.Выбор события из справочника событий уведомлений
image::select-event.png[Выбор события из справочника событий уведомлений]
+
. Кнопки:
+
* Кнопка *Сохранить* -- сохраняет настройки рассылки уведомлений.
* Кнопка *Отменить* -- отменяет все изменения в карточке.
